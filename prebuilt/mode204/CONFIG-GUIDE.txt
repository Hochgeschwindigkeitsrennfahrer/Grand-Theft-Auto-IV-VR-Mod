gtaiv-dxvk-vr — Mode 204 config files (next to GTAIV.exe)
=======================================================

gtaiv_dxvk_vr.stereo
  204 = fused parent dual (milestone — keep this)
  203 = previous hook (better size feel, weaker near fusion)
  200 = parent dual older
  0   = VR off (flat DXVK)

gtaiv_dxvk_vr.ipd
  Eye separation. Live good: 2. F8 cycles.

gtaiv_dxvk_vr.stereoscale
  Stereo strength. Live good: 130. F6 cycles. Higher = stronger 3D.

gtaiv_dxvk_vr.scale
  TrueWorldScale base (also F11). Higher = smaller world.
  Start 100; raise if world feels huge.

gtaiv_dxvk_vr.vres
  Eye canvas resolution. Pack default 2048. F5 cycles higher.
  Very high values (3000+) need a strong GPU.

gtaiv_dxvk_vr.fpfov
  Three numbers: on-foot / vehicle / aim FOV. Pack: 110 110 110

gtaiv_dxvk_vr.vehcamoff
  Vehicle camera offset. Pack: 0 -12 0

gtaiv_dxvk_vr.pedhide
  1 = hide player ped in FP (if used). Pack: 0

commandline.txt
  square-aspect square game resolution (pack: 1440x1440 windowed).
  Rename to commandline.txt.off for normal widescreen.
  Keep a copy as commandline.txt.vr-square to switch back later.
  Change -width/-height together (same number) for other square sizes.
  Full restart after any change.

dxvk.conf
  Optional DXVK tweaks. Pack may include enableAsync for less stutter.

GTAIV.dxvk-cache
  Pre-warmed shader cache. Keep it; first run still may compile some.

Log: gtaiv_dxvk_vr.log next to GTAIV.exe
